# Security Policy

## Supported version

Security fixes are applied to the latest state of the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential, or private target URL. Use GitHub's private vulnerability reporting feature when it is available for this repository.

Include the affected file or workflow, reproduction steps, likely impact, and any safe mitigation already tested. Do not test against a site you do not own or have permission to assess.
